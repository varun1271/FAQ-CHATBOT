# CodeGPT - Your Personal AI Coding Assistant

CodeGPT is a modern, responsive web application dedicated exclusively to programming. It provides detailed explanations for coding topics and advanced code debugging/fixing features.

## Features

- **Learn Coding**: Get comprehensive guides for over 40+ programming topics. Use the `/` prefix (e.g., `/python`, `/loops`).
- **Fix My Code**: Paste your code and get a detailed report with detected errors, corrections, and optimization tips.
- **AI-Powered Guardrails**: Strictly restricted to programming-related content.
- **Modern UI/UX**: Glassmorphism effects, smooth animations, and dark/light theme support.
- **Search System**: Fuzzy search and autocomplete for slash commands.
- **History**: Local search and fix history.
- **Utility Tools**: Copy code blocks, download responses, and character counter.

## Tech Stack

- HTML5
- CSS3 (with CSS Variables & Glassmorphism)
- Vanilla JavaScript
- [Marked.js](https://marked.js.org/) for Markdown rendering
- [Highlight.js](https://highlightjs.org/) for syntax highlighting
- [Font Awesome](https://fontawesome.com/) for icons

## Project Structure

- `index.html`: Main application structure.
- `style.css`: Modern, responsive styling.
- `script.js`: Core application logic and knowledge base.
- `assets/`: Directory for images and icons.
